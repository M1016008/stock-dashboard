## Evidence contract

- `large_holder_edinet_code_bridge`: official EDINET code list ZIP/CSV, code, security code, submitter name, listing state, snapshot date, archive SHA-256, row evidence and hash. Name differences are warnings, never identity keys. The official [EDINET API reference](https://disclosure2dl.edinet-fsa.go.jp/guide/static/disclosure/download/ESE140206.pdf) supplies the [fixed ZIP URL](https://disclosure2dl.edinet-fsa.go.jp/searchdocument/codelist/Edinetcode.zip). This source is a **current snapshot**, not a historical code-list archive.
- `large_holder_issuer_capital_structure`: separate issuer annual-report XBRL, EDINET issuer identifier, official submitted timestamp, filing-date issued class facts, issued units, quantity unit, exchange-description cell, lot size when disclosed, complete-table flag, XBRL/table hashes, document ID and source URL. The issued-shares table must enumerate exactly the positive, dimensioned share-class facts; a flat aggregate is insufficient.
- `large_holder_position_certifications`: explicit vs cross-document certification method, evidence strength, and five-piece machine-readable evidence chain. The instrument, unadjusted JPX/J-Quants price and local adjusted-price reconciliation remain separate evidence.

`EXPLICIT_FILING` requires the direct holding note to identify class, unit and exact quantity. `CROSS_DOCUMENT_UNIQUE` requires an official identifier bridge available before the cutoff, a complete issuer statutory class table submitted no later than the obligation-date knowledge cutoff, exactly one eligible class, an explicitly listed exchange, matching quantity/price units, and a dated instrument/price mapping. Multiple classes, including a non-listed preferred class without independent legal exclusion proof, fail closed. An explicit holding note with a conflicting quantity cannot be overridden by a single-class report. Neither a trading lot nor an adjusted close is multiplied into the holding value.

The ZIP date contains no publication time; same-day use is disallowed. The separately captured issuer annual-report submission timestamp comes from the EDINET documents index, not local download time. A future annual report, code list, instrument or price cannot establish a past event. Filing quantities are known only after the large-holder report is submitted; even an ex-post obligation-date price must never be presented as a signal available before that submission. The separate current amount requires the latest effective, nonwithdrawn position and a fresh official price, identity bridge and current capital relation. `pitValuationReady` and current/public readiness are distinct.

REIT is not a common-stock shortcut. Its annual-report capital block proves a UNIT quantity, and its price must be JPY_PER_UNIT with an independently identified JPX REIT instrument. The issuer's capital block alone does not prove its exchange class. The current EDINET code-list row for 3290 has no security code; the REIT bridge is therefore unavailable, regardless of the XBRL quantity. Infrastructure funds, ETFs and other product types remain excluded rather than inherited from common stock.
